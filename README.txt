Dexter DTV / Novamedia · личный плагин для Lampa / ByLampa v0.3.0

1. Поместите dexter-dtv.js на HTTPS-хостинг, который отдаёт файл как JS (например, GitHub Pages).
2. Lampa -> Настройки -> Расширения -> Добавить плагин -> HTTPS-ссылка на dexter-dtv.js.
3. Перезапустите Lampa и откройте карточку Dexter / Декстер (2006).
4. Нажмите «Декстер · DTV», выберите серию, вставьте ПРЯМОЙ полный HLS/m3u8 URL.
5. Для уже сохранённой серии нажатие сразу запускает Lampa.Player; выбранный внешний плеер DDD должен получить поток через приложение Lampa.
6. Нажмите «Изменить ссылку серии...», когда адрес истёк.
7. Для личного Autoposter API: в меню «Автоисточник · API» введи полный HTTPS-адрес `/api/internal/media/resolve`, затем одноразовый ключ устройства `pm_…`. Плагин отправляет POST с параметрами серии и ключом в `Authorization`; ключ не вшит в публичный JS.
8. «Получить ссылку автоматически (эксперимент)» пробует только CORS-доступный HTML источника и никогда не обходит проверки человека. При блокировке используйте ручной ввод или разрешённый сервер-резолвер.

ВАЖНО:
* URL серий не вшиты в публичный JS и сохраняются лишь в Lampa.Storage текущего устройства/профиля.
* Плагин НЕ получает ссылки с веб-страниц автоматически и НЕ обновляет временные токены.
* v0.3.0 штатно закрывает Lampa.Select и возвращает исходный контроллер карточки после Back, выбора серии и выхода из ввода. Это исправлено автоматическими тестами с имитацией API Lampa, но работу пульта и возврат из DDD всё равно нужно проверить на Haier Android TV с bylampa.online.
* Ссылка на страницу сериала НЕ подходит: нужен прямой URL вида https://.../manifest.m3u8.
* Не публикуйте URL с временными ключами в публичном GitHub-репозитории.
* Плагин — пробная сборка, совместимость с ByLampa на конкретном ТВ ещё не проверена.
